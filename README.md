# Java Lab Programs - 3rd Semester

A collection of Java programs created for third-semester lab practice.

## Programs

| File | Description |
| --- | --- |
| [`area.java`](./area.java) | Calculates and prints the area of a circle using a radius of `10.8` and an approximation of pi (`3.1416`). |

## Requirements

- Java Development Kit (JDK) installed
- `javac` and `java` available on your `PATH`

Check your Java installation with:

```bash
java -version
javac -version
```

## Run a program

From the repository directory, compile and run the circle-area program:

```bash
javac area.java
java area
```

Expected output:

```text
the area of the circle is 366.436224
```

The program uses the formula `area = pi * radius * radius`. Edit the radius in
`area.java` to calculate the area for a different circle.
